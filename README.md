# Backrooms: Project Liminal (Proto 1)

A web-based 3D horror experience built with React, Three.js, and React Three Fiber.
Inspired by the "Backrooms" creepypasta (Level 0).

## 🎮 How to Play
- **Move:** WASD
- **Sprint:** Shift
- **Jump:** Space
- **Look:** Mouse (Click to lock cursor)
- **Interact:** E

## 🎯 Objective
Find the **Manila Room** to escape.
Avoid the **Shadow Man**.
Watch your **Sanity** - don't stay in the dark too long.

## 🛠️ Tech Stack
- **Framework:** React + Vite
- **3D Engine:** Three.js / @react-three/fiber
- **Physics:** @react-three/cannon
- **Post-Processing:** @react-three/postprocessing (VHS Effects)
- **State Management:** Zustand

## 🚀 Installation
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the local server.
